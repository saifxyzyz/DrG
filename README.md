Project Mission:
To rigorously test and validate the capabilities of Google's MedGemma on dynamic, real-world stress data. This project explores the frontiers of multimodal integration, challenging the model to interpret high-velocity physiological signals (EDA, HR, Temp) from wearable devices and convert them into actionable, clinical-grade mental health insights.

Core Objectives:

Dynamic Analysis: Evaluate MedGemma's ability to track and interpret temporal fluctuations in physiological stress markers.

Wearable Integration: Assess the feasibility of embedding MedGemma-driven insights into the feedback loops of consumer wearable devices.

Personalized Intervention: Move beyond static dashboards by generating context-aware, empathetic interventions based on real-time biometric states.



Dataset: https://physionet.org/content/wearable-exam-stress/1.0.0/
